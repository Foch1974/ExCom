ExCom v3.1 integrates **4 deterministic Python 3 stdlib engines** (`skills/excom/scripts/`) into a single vertical spine across **both** `MODE = "CODE"` (software, quant trading, AI/data, embedded) and `MODE = "METIER"` (corporate/tax, real estate, global sourcing, legal, personal wealth/life):

## Non-Negotiable Operating Laws

1. **US-English Visual Chrome + Sovereign User-Language Explanations**: All built-in dashboard UI chrome, CLI badges, and schema keys use standard **US English (`en-US`)** for universal open-source compatibility, while **100% of your explanations, intake questions, rationale sentences (`plain_sentence`), legal/business deliverables, and conversational replies MUST be written in the exact language used by the user**.
2. **Zero Mental Math & Dated Provenance (`ADD_03`)**: Never compute financial, tax, or performance numbers in your head—run a deterministic Python script on disk and pass `calc_script_path` + `calc_output_path`. In `METIER` mode, every `verified_sources` entry must be a structured object (`ref`, `url_or_file`, `date`, `verbatim_excerpt`).
3. **Never Re-Propose Buried Dead-Ends (`ADD_02`)**: Always pass `--ledger-dir` to `porte0_carte_decideur.py` and log any failed experiment via `record-dead-end` so rejected hypotheses are permanently blocked across future conversations.
4. **Lossless Anti-Amnesia Anchor (`ADD_04`)**: Never summarize a previous summary. Always rely on `CONTEXT_ANCHOR.md` compiled deterministically by `zero_oubli_runner.py` directly from the primary JSON ledgers.
5. **Physical `PreToolUse` Protection (`ADD_01`) & Read-Only Safety**: On brand-new project folders, install the physical `PreToolUse` firewall via `install-hooks`; on existing repositories that already carry their own `.agents/hooks.json`, `install-hooks` automatically skips overwriting to preserve existing bespoke locks.
6. **Zero Dead HTML Links**: Launch standalone HTML dashboards directly in the OS default browser (`Start-Process` / `open` / `xdg-open`) or publish to **Google Sheets / Google Docs** when connected.
